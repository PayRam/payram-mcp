# Decision: adopt MCP TypeScript SDK v2 (protocol 2026-07-28)

- **Date:** 2026-09-16
- **Status:** accepted (upgrade requested by the maintainer)
- **Rules:** R-LIB-VET, R-REUSE-FIRST, R-API-FOR-AGENTS

## Context

The server used `@modelcontextprotocol/sdk` 1.x, which only speaks the 2025 protocol revisions. MCP 2026-07-28 makes the protocol stateless (no `initialize`, per-request `_meta`, `server/discover`, cache hints, multi-round-trip input). That matches how mcp.payram.com runs: a fresh server per request on Vercel.

## Decision

Replace `@modelcontextprotocol/sdk` with the v2 packages `@modelcontextprotocol/server`, `/node` and `/express` (and `/client` for tests). Requests are routed by protocol era:

- **2026-07-28:** `createMcpHandler(factory, { legacy: 'reject' })`.
- **2025-era:** a per-request `NodeStreamableHTTPServerTransport` with JSON responses, so existing clients see no behaviour change.

| Check | Result |

## Consequences

- Dependencies: `zod` ≥ 4.2 (already on 4.4), and `@hono/node-server`, pulled in by `/node`.
- Tool input and output JSON Schemas are now emitted in the 2020-12 dialect.
- The hosted HTTP+SSE transport is not served; `/mcp/sse` answers 410.
- Pin minor versions and review SDK updates like any other dependency.
